1. Formulaire → PHP

<form action="traitement.php" method="POST">
  <input type="text" name="mat">
  <input type="submit" name="btn_send">
</form>
if (isset($_POST['btn_send'])) {
  $mat = $_POST['mat'];
  echo "Reçu : ".$mat;
}

$_POST['name'] تجيب القيمة لي كتبها المستخدم. isset تتأكد أن الزر تضغط عليه.

2. Connexion

connexion.php

$server = "localhost"; $user = "root";
$pw = ""; $bd = "bac2024_db";

$conn = mysqli_connect($server, $user, $pw, $bd);

4 معطيات بالترتيب: السيرفر، اليوزر، الباسورد (فارغ في XAMPP)، واسم الـ base. المتغير $conn هو الاتصال لي نستعملوه في كل الطلبات.

3. INSERT / UPDATE / DELETE

$req = "INSERT INTO eleve (cin, nom, prenom)
        VALUES ('$cin', '$nom', '$prenom')";
$res = mysqli_query($conn, $req);

"UPDATE eleve SET moyenne = 15.5 WHERE cin = '$cin'"
"DELETE FROM eleve WHERE cin = '$cin'"

if (mysqli_affected_rows($conn) > 0) {
  echo "Opération réussie !";
}

mysqli_query($conn, $req) تبعث الطلب للقاعدة وترجّع true/false. ما تنساش WHERE في UPDATE وDELETE، وإلا تبدّل ولا تحذف الكل!

mysqli_affected_rows($conn) ترجّعلك قدّاش من سطر تأثّر بآخر طلب (INSERT/UPDATE/DELETE). كان ترجّع 0 يعني ما تبدّل شي.

4. SELECT et affichage

$res = mysqli_query($conn, "SELECT * FROM eleve");

if (mysqli_num_rows($res) > 0) {
  while ($row = mysqli_fetch_array($res)) {
    echo $row['cin'] . " " . $row['nom'];
  }
} else { echo "Aucun élève trouvé !"; }

num_rows تعطيك عدد السطور. fetch_array تجيب سطر في كل دورة من الـ while لين تخلص. تقرا بإسم العمود $row['nom'] ولا بالرقم $row[0].

5. Affichage en tableau + style

PHP : générer le tableau

echo "<table class='tab'>";
echo "<tr><th>CIN</th><th>Nom</th><th>Moyenne</th></tr>";
while ($row = mysqli_fetch_array($res)) {
  echo "<tr>";
  echo "<td>" . $row['cin'] . "</td>";
  echo "<td>" . $row['nom'] . "</td>";
  echo "<td>" . $row['moyenne'] . "</td>";
  echo "</tr>";
}
echo "</table>";

CSS : style du tableau

.tab { border-collapse: collapse; width: 100%; }
.tab th, .tab td {
  border: 1px solid #333;
  padding: 8px; text-align: center;
}
.tab th { background-color: #6b4fbb; color: white; }
.tab tr:nth-child(even) { background-color: #f3eefc; }

echo تكتب كود HTML: tr سطر، th عنوان عمود (مرة وحدة قبل الـ while)، td خانة (داخل الـ while، سطر لكل نتيجة). باش تزيّن الجدول عطيه class='tab' واكتب الستايل في ملف CSS ولا داخل <style>. بالسرعة: <table border='1'> تعطيك إطار بلا CSS.

6. Les fonctions

mysqli_connect()تفتح الاتصال بالسيرفر والـ base
mysqli_query()تبعث طلب SQL
mysqli_num_rows()عدد السطور الراجعة من SELECT
mysqli_affected_rows()عدد السطور لي تأثّرو (INSERT/UPDATE/DELETE)
mysqli_fetch_array()تجيب سطر في كل مرة

7. À retenir !

  1. اتصل بالـ base بـ mysqli_connect
  2. ابعث الطلب بـ mysqli_query
  3. بعد INSERT/UPDATE/DELETE استعمل mysqli_affected_rows
  4. اقرا SELECT بـ fetch_array داخل while واعرضو في table
نصيحة: الطلبات هنا مكتوبة كيما في الامتحان. في المشاريع الحقيقية استعمل prepared statements باش تحمي من SQL injection.

Select · Radio · Checkbox

كيفاش نقرا قيم عناصر الفورم في PHP

8. Select / option

<select name="classe">
  <option value="">-- Choisir --</option>
  <option value="4info">4 Info</option>
  <option value="4math">4 Math</option>
</select>
$classe = $_POST['classe'];
echo $classe;   // 4info

PHP تقرا الـ value متاع الـ option المختارة، مش النص لي يظهر للمستخدم. $_POST['classe'] تعطيك القيمة مباشرة.

اختيار متعدد؟ زيد multiple وسمّيها name="classe[]"، والنتيجة array تقراها بـ foreach.

9. Radio

<input type="radio" name="genre" value="M"> Garçon
<input type="radio" name="genre" value="F"> Fille
if (isset($_POST['genre'])) {
  $genre = $_POST['genre'];   // M ou F
}

كل الـ radio لازم عندهم نفس الـ name باش تختار وحدة برك. كان المستخدم ما اختار حتى وحدة، ما يتبعث شي، علاش نستعمل isset.

10. Checkbox

<!-- واحد -->
<input type="checkbox" name="newsletter" value="oui">

<!-- برشا -->
<input type="checkbox" name="lang[]" value="php"> PHP
<input type="checkbox" name="lang[]" value="js"> JS
if (isset($_POST['newsletter'])) { echo "coché"; }

if (isset($_POST['lang'])) {
  foreach ($_POST['lang'] as $l) {
    echo $l . " ";
  }
}

الـ checkbox لي ما تمّش اختياره ما يتبعثش أصلا. بالـ [] في الاسم، كل القيم المختارة تتجمع في array.

11. Résumé

text / select$_POST['name'] تعطيك القيمة مباشرة
radioisset وبعدها $_POST['name']
checkbox (واحد)isset برك: مختار ولا لا
checkbox (برشا)isset + foreach على الـ array

12. Exemple complet

HTML : formulaire.html

<form action="traitement.php" method="POST">
  <input type="text" name="nom">
  <select name="classe">
    <option value="4info">4 Info</option>
    <option value="4math">4 Math</option>
  </select>
  <input type="radio" name="genre" value="M"> M
  <input type="radio" name="genre" value="F"> F
  <input type="checkbox" name="lang[]" value="php"> PHP
  <input type="checkbox" name="lang[]" value="js"> JS
  <input type="submit" name="btn_send">
</form>

PHP : traitement.php

if (isset($_POST['btn_send'])) {
  $nom    = $_POST['nom'];
  $classe = $_POST['classe'];

  if (isset($_POST['genre'])) {
    $genre = $_POST['genre'];
  }
  if (isset($_POST['lang'])) {
    foreach ($_POST['lang'] as $l) {
      echo $l . " ";
    }
  }
}

الاسم والـ select يتقراو مباشرة. الـ radio يحتاج isset لأنو ممكن ما يتختارش. الـ checkbox يتبعث كـ array فنقراوه بـ foreach.
